control flow:
app.js (router i.e short_url) -> routes (createShortUrl) -> controller(createshorturlWithoutUserservice) ->services(saveShortUrl) -> dao (saveShortUrl , getShortUrl) -> models(define db schema) 

() contains the function it used of next module.

in service we use generateNanoId function defined in the helper.js in the utils. 
config contains mongodb.controller.js which establishes the connection betwee application and mongodb
